# Avatar video channel — Simli avatar over SmallWebRTC (aiortc, all platforms).
#
# IMPORTANT: we deliberately do NOT use the pipecat `[simli]` extra. That extra
# hard-pins `simli-ai~=0.1.10`, whose WebSocket protocol (/StartWebRTCSession) was
# RETIRED by Simli — every connection now returns HTTP 403 (verified by probing
# every endpoint/auth variant against api.simli.ai). The live servers only serve
# the 2.0.x protocol (/compose/token + /compose/webrtc/p2p with x-simli-api-key).
#
# So we install simli-ai 2.0.x DIRECTLY (below) and drive it with our own
# AgentSimliVideoService (channels/avatar_video/processors/simli_service.py),
# which replicates pipecat's SimliVideoService FrameProcessor interface on the
# 2.0.x client: SimliClient(api_key=..., config=SimliConfig(faceId=...));
# client.start(); client.sendImmediate(). pipecat's own SimliVideoService is never imported.
#
# [webrtc] → SmallWebRTCTransport (browser↔backend WebRTC). Pulls aiortc + cv2.
# [livekit] → LiveKitTransport (the meeting channel's room transport). Pulls the
#             livekit / livekit-api SDK that pipecat.transports.livekit imports.

# RAG — Qdrant hybrid retrieval (dense + sparse). Both lazy-imported in
# rag/qdrant_store.py.
#   qdrant-client : the Qdrant client (hybrid query: dense + sparse, RRF fusion).
#   fastembed     : the SPARSE side only (Qdrant/bm25 keyword vectors), used to
#                   embed the query's sparse vector. Tiny, CPU, downloads a small
#                   BM25 vectorizer on first use. The DENSE side is OpenAI
#                   text-embedding-3-large (via the openai package above).
#                   The model is warmed at server boot (main.py lifespan →
#                   rag.retriever.warmup_rag) and cached at FASTEMBED_CACHE_PATH.
#                   DOCKER IMAGE OWNERS: bake the model into the image so
#                   air-gapped pods never download at runtime:
#                     ENV FASTEMBED_CACHE_PATH=/app/.fastembed_cache
#                     RUN python -c "from fastembed import SparseTextEmbedding; SparseTextEmbedding('Qdrant/bm25', cache_dir='/app/.fastembed_cache')"
